# Image Studio 首次使用指南

## 一、这是什么

一套**脱离 QQ 机器人、可单独使用**的本地 AI 生图工作室：

- 中文描述 → Danbooru 英文标签（本地 Qwen3-8B 翻译，离线）
- 标签 → ComfyUI 生图（本地 SDXL / Illustrious）
- 浏览器界面，双击 `start.bat` 即用

## 二、硬件要求

| 项目 | 要求 |
|---|---|
| 显卡 | **NVIDIA，显存 ≥ 8 GB**（低于 8 GB 页面会直接提示不可用） |
| 显存建议 | 12 GB 以上体验完整；8–10 GB 需接受翻译变慢（约 30–60 秒/句） |
| 磁盘 | 约 25 GB（含 ComfyUI 运行时、WAI 底模、Qwen3-8B） |
| 系统 | Windows 10/11 x64 |

> 8 GB 显存说明：翻译实例会自动只把 16 层放上显卡，其余层用 CPU，速度慢但能出结果；翻译与生图**不能同时跑**，系统会自动互斥（生图前自动停翻译实例释放显存）。

## 三、启动 / 停止

- 启动：双击 **`start.bat`**，等浏览器自动打开 `http://127.0.0.1:34567`
- 停止：关闭那个命令行窗口，或双击 **`stop.bat`**

首次生图时 ComfyUI 冷启动需要 1–3 分钟，属正常现象。

## 四、界面用法

1. **翻译卡片**：输入中文描述 → 点「翻译为标签」→ 结果自动填入下方提示词框
2. **生图卡片**：核对提示词、尺寸、步数、数量 → 点「生成图片」
3. 生成结果可单张下载；**点图片可放大预览**（点击遮罩 / 右上 ✕ / `Esc` 关闭）

底模：**WAI Illustrious SDXL** / **NoobAI XL v-pred**（均已随包，界面切换）。默认分辨率 1360×768。

### 右侧「角色提示词」面板

宽屏时页面右边会有固定面板，用来把 LoRA 和该角色的提示词 TXT 绑定起来：

1. 先在「LoRA 管理」里选中一个 LoRA
2. 点面板里的「选择 TXT 并绑定…」，选该角色的提示词 txt（UTF-8）
3. 绑定后：**切到哪个 LoRA，面板就显示哪个角色的提示词**；要复制就在文本框里 `Ctrl+A` 全选、`Ctrl+C` 复制
4. 提示词可直接在面板里编辑（失焦自动保存）、点「保存」手动存、点「删除绑定」解除
5. 面板标题右侧的「? 用法」可随时展开/收起操作说明

绑定数据存在 `state\character-prompts.json`；面板底部「已绑定角色」可一键切换。

### 右下角「宁宁小助手」

页面右下角有个小助手形象（和博客页头同一个角色图），点一下弹出气泡面板，里面有 8 个帮助按钮：

翻译怎么用 / 生图参数怎么设 / 高清修复 / LoRA 安装与加载 / 角色提示词 / 显存不够·变慢 / 出问题怎么办 / 启动与停止

点任一按钮显示对应说明，左上「← 返回」回列表；点 `✕`、点页面其他位置或按 `Esc` 可关闭。

### 高清修复（Hires fix）

勾选后走「小图出底 → 像素域放大 → 低噪声细化」两阶段：

1. 基础图 = 目标尺寸 ÷ `hiresScale`，并夹在 `maxPixels` 以内（默认 1.4 MP）
2. 基础图按 denoise=1.0 正常出图
3. 用 `hiresUpscaleModel`（默认 `4x-UltraSharp.pth`）放大，再 lanczos 缩回目标尺寸
4. 第二阶段 denoise=`refineDenoise`（默认 0.40）、步数=`refineSteps`（默认 26）重绘补细节

可调参数都在 `server\config.json` 的 `image` 段：`hiresScale`、`hiresMode`、`hiresUpscaleModel`、`refineDenoise`、`refineSteps`、`maxPixels`。改完重启后端生效；单次请求也可在 `/api/generate` body 里同名覆盖。


## 五、底模 / LoRA / 提示词

本整合包**自带两个底模：WAI Illustrious SDXL 和 NoobAI XL v-pred**，且**只允许用这两个**（界面上不可添加其它底模）。LoRA、提示词不打包，按下面方式接入：

### 1. 底模（固定两个，不可新增）
- 界面「底模」下拉只有两个选项：
  - **WAI Illustrious**：dpmpp_2m + karras，26 步，负面词含鸟类压制链
  - **NoobAI XL v-pred**：euler + normal，28 步，负面词为官方风格（含防白边/letterboxed）
- **切换底模时，负面提示词、步数、CFG 会自动切换成该底模的默认值**；NoobAI 还会自动在正面提示词前补质量词（masterpiece…）。
- 后端强制只从配置登记的两个底模里选，`checkpoints\` 里多放的文件不会被用到。

> v-pred（NoobAI）不能用 karras、不能用带权重的负面词，否则颜色诡异或压出黑块 —— 这些默认值已经按官方建议配好，不要手动改 `server\config.json` 里的 sampler/scheduler。

### 2. 放自己的 LoRA
**方式 A（推荐，界面直接装）**：页面「LoRA 管理」卡片 → 点「安装 LoRA 文件…」选中 `.safetensors`
→ 自动上传到 `ComfyUI\ComfyUI\models\loras\` 并出现在下拉列表里 → 选权重（0~1.5）→ 生图时自动带上。

**方式 B（手动放文件）**：把 `.safetensors` 放进 `ComfyUI\ComfyUI\models\loras\`，然后点「刷新列表」。
找不到目录时点「复制路径」，把路径粘到资源管理器地址栏即可（若「打开 LoRA 文件夹」没弹窗，通常是被浏览器挡在后面，或程序不是从桌面启动的）。

也支持在提示词里写 `<lora:你的lora文件名:0.8>`（ComfyUI 原生语法，与界面选择二选一即可）。

### 3. 放自己的 VAE / 放大模型
```
ComfyUI\ComfyUI\models\vae\
ComfyUI\ComfyUI\models\upscale_models\
```

### 4. 提示词（你自己的提示词文本）
放在任意目录，例如新建 `ComfyUI\ComfyUI\models\user-prompts\`，把自己的中文/英文提示词 txt 放进去，
生图时复制内容粘贴到界面即可（本工具不强制读取固定目录）。

> 建议先只放 1 个底模 + 1 个 LoRA 验证能出图，再批量加，避免显存/加载问题难排查。

## 六、常见问题

**Q：页面提示“显存不足，整合包不可用”？**
A：检测到可用显存低于 8 GB。请关闭其他占显存的程序，或换显存更大的显卡。

**Q：翻译很慢（30–60 秒）？**
A：处于低显存模式（<10 GB），翻译层大部分在 CPU 跑。可先翻译好标签，再点生图（生图会释放翻译显存）。

**Q：生图很久没反应，是不是卡住了？**
A：高清修复 + 1920×1080 + LoRA 正常就要 **60~120 秒**（实测 68~76 秒），按钮上会显示已用秒数。
如果最后报「ComfyUI 任务丢失」或「ComfyUI 执行失败」，说明任务被中断 / ComfyUI 重启 / 显存不足 OOM，
重新点一次生成即可；连续 OOM 就降低分辨率或关掉高清修复。

**Q：生图报“ComfyUI 启动失败”？**
A：检查 `ComfyUI\ComfyUI\main.py` 与 `ComfyUI\python_embeded\python.exe` 是否存在；
首次启动较慢，等待 1–3 分钟。

**Q：磁盘越来越大？**
A：ComfyUI 会把图写到 `ComfyUI\ComfyUI\output`。本整合包默认**生成完就把服务端那张图删掉**
（图已经在浏览器里了），并在启动时按「保留 7 天 / 最多 200 张」兜底清理。
想手动清：点「生成结果」旁的「清理服务端输出图」，或调 `POST /api/output/clean`。
策略在 `server\config.json` 的 `image.outputCleanup`（`afterDownload` / `maxAgeDays` / `maxFiles`）。

**Q：怀疑翻译结果被旧缓存影响？**
A：点翻译卡片里的「清空翻译缓存」，会一次删掉普通 + 加权两套缓存（`state\tag-cache*.jsonl`），
之后同样的句子会重新翻译。

**Q：想换底模？**
A：直接在界面「底模」下拉里切 WAI / NoobAI，负面词和采样参数会自动跟着换。
本整合包**不支持添加第三个底模**（后端只认配置里登记的两个）。

**Q：缓存/日志在哪？**
A：`state\tag-cache.jsonl`（翻译缓存）、`state\tag-cache-weight.jsonl`（加权缓存）。
删掉即可重建。
